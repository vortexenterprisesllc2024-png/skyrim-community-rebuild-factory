To compile:

1.Get the desired SKSE sources and open the included project in VS
2.Change the solution configuration to 'Release'
3.Change skse64's build configuration type to 'Static Library'
4.Disable skse64's build events.
5.Build skse64
5.Build skse64_common
6.Add Honed Metal's included VS project to the solution and re-add or adjust the references' path if needed.
7.Build Honed Metal
